코드브레이커(Code Breaker) 개발일지

작성일: 2026-05-05 | 작성자: imgtocode

👾 프로젝트 개요

'코드브레이커'는 오락실에서 즐기던 클래식 스페이스 인베이더의 감성을 웹 브라우저로 옮겨온 아케이드 슈팅 게임입니다. 플레이어는 'JS' 마크가 새겨진 기체를 조종하여 다가오는 에러 코드(적)들을 격파해야 합니다. 외부 이미지 파일 없이 자바스크립트의 2차원 배열과 Canvas API만을 이용하여 레트로 픽셀 아트와 타격감을 구현한 것이 핵심입니다.

⚠️ 핵심 트러블슈팅: 코드 파편 파티클(Particle) 효과

문제 상황: 단순히 적이 사라지는 것만으로는 슈팅 게임 특유의 '타격감'이 부족했습니다. 타격감을 살리기 위해 폭발 효과가 필요했지만, 이미지 스프라이트를 사용하면 렌더링 리소스가 무거워지고 코딩 컨셉과도 어울리지 않았습니다.

해결 방법: 적을 격파할 때마다 사방으로 흩어지는 텍스트 파티클(Particle) 시스템을 직접 구현했습니다. 폭발 파편으로 "<div>", "err", "404", "=>" 같은 자바스크립트 및 웹 코드 텍스트들을 랜덤하게 출력하여 디버깅 액션이라는 게임의 컨셉을 살렸습니다. 아래는 그 핵심 로직입니다. 


// 폭발 시 흩어지는 코드 파편 파티클 클래스
const codeFragments = ["<div>", "</span>", ";", "err", "404", "{}", "=>", "let", "const"];

class Particle {
    constructor(x, y, color) {
        this.x = x;
        this.y = y;
        // 배열에서 랜덤한 코드 텍스트 조각 선택
        this.text = codeFragments[Math.floor(Math.random() * codeFragments.length)];
        this.vx = (Math.random() - 0.5) * 4; // X축 무작위 흩어짐
        this.vy = (Math.random() - 0.5) * 4; // Y축 무작위 흩어짐
        this.alpha = 1;
        this.color = color;
    }
    update() {
        this.x += this.vx;
        this.y += this.vy;
        this.alpha -= 0.02; // 서서히 투명해지며 사라짐
    }
    draw() {
        ctx.save();
        ctx.globalAlpha = this.alpha;
        ctx.fillStyle = this.color;
        ctx.font = "10px monospace";
        ctx.fillText(this.text, this.x, this.y); // Canvas에 텍스트 렌더링
        ctx.restore();
    }
}

✨ 결과 및 느낀 점

배열을 이용해 적(Enemy)과 플레이어(Player)의 픽셀 아트를 직접 도트로 찍어내고 렌더링하는 과정이 매우 흥미로웠습니다. 특히 5스테이지마다 등장하는 거대한 '보스' 몬스터에 HP 시스템과 그림자(Shadow Blur) 효과를 적용하니 긴장감이 한층 더 살아났습니다.

Firebase와 연동하여 랭킹 시스템(saveGameScore)까지 성공적으로 부착했으며, 20스테이지를 모두 클리어하면 'ALL COMPILED' 메시지를 띄우는 것으로 디버깅 게임의 세계관을 완성했습니다. 다음에는 적들의 다양한 공격 패턴이나 관통형 무기 아이템을 추가해 볼 계획입니다.
