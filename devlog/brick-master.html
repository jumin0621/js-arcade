브릭 마스터(Brick Master) 개발일지

작성일: 2026-04-24 | 작성자: imgtocode

🧱 프로젝트 개요

'브릭 마스터'는 아케이드 게임의 대명사인 벽돌 깨기(Breakout)를 바닐라 자바스크립트로 재현한 프로젝트입니다. 이전 스네이크 게임이 배열 구조에 집중했다면, 이번에는 HTML5 Canvas의 2D 렌더링과 오브젝트 간의 물리 반사 및 충돌 감지(Collision Detection)를 구현하는 데 초점을 맞추었습니다.

⚠️ 핵심 트러블슈팅: 벽돌과 공의 충돌 감지

문제 상황: 공이 벽돌을 통과해버리거나, 닿지도 않았는데 벽돌이 부서지는 현상이 발생했습니다. 동그란 공과 네모난 벽돌의 교집합을 어떻게 수학적으로 깔끔하게 계산할 것인지가 가장 큰 난관이었습니다.

해결 방법: 2D 게임 개발에서 가장 널리 쓰이는 AABB (Axis-Aligned Bounding Box) 충돌 감지 개념을 적용했습니다. 공의 중심 좌표(x, y)가 벽돌의 상하좌우 경계선 내부에 들어오는 순간을 포착하고, 충돌 시 공의 Y축 방향(dy)을 반대로 뒤집어 튕겨 나가는 효과를 구현했습니다. 


// 공과 벽돌의 충돌 감지 로직
function collisionDetection() {
    for (let c = 0; c < brickColumnCount; c++) {
        for (let r = 0; r < brickRowCount; r++) {
            let b = bricks[c][r];
            // 벽돌이 살아있을 때만 (status === 1) 계산
            if (b.status === 1) {
                // 공의 X, Y 좌표가 벽돌의 영역 안에 들어왔는지 검사
                if (x > b.x && x < b.x + brickWidth && y > b.y && y < b.y + brickHeight) {
                    dy = -dy;      // 공을 반대 방향으로 튕겨냄
                    b.status = 0;  // 벽돌 깨짐 상태로 변경
                    score += 10;   // 점수 증가
                }
            }
        }
    }
}
