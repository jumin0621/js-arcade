바운스볼(Bounce Ball) 개발일지

작성일: 2026-04-25 | 작성자: imgtocode

☄️ 프로젝트 개요

'바운스볼'은 중력과 탄성을 이용해 맵을 탈출하는 정통 플랫폼 게임입니다. 이 프로젝트의 핵심은 gravity(중력)와 jumpForce(반발력)를 수학적으로 구현하여 공 특유의 쫄깃한 움직임을 만드는 것이었습니다. 최근 10단계 맵 리뉴얼을 진행하며, 가시 함정과 슈퍼 점프 타일 등 동적인 기믹들을 추가했습니다.

⚠️ 핵심 트러블슈팅: 타일 종류에 따른 커스텀 반발력 구현

문제 상황: 기본 벽돌(1)에서는 일반적인 높이로 튕겨야 하지만, 노란색의 슈퍼 점프 타일(3)을 밟았을 때는 훨씬 더 높이 튕겨 오르도록 만들어야 했습니다. 기존의 충돌 감지 함수(checkWall)는 단순히 벽이 "있다(true) / 없다(false)"만을 반환했기 때문에 어떤 타일을 밟았는지 알 수 없었습니다.

해결 방법: 충돌 감지 함수가 단순한 불리언(Boolean) 값이 아닌, 충돌한 타일의 번호를 직접 반환(Return)하도록 업그레이드했습니다. 특히 슈퍼 점프 타일(3)을 밟았을 경우 우선순위를 부여하여, 업데이트 루프 안에서 jumpForce에 1.6배의 가중치를 곱해주는 방식으로 해결했습니다. 


// 1. 타일 번호를 반환하는 충돌 감지
function checkWall(x, y, map) {
    let hitType = 0;
    for (let p of pts) {
        // ... (좌표를 그리드 인덱스로 변환) ...
        let t = map[gy][gx];
        if (t === 1) hitType = 1; // 일반 벽
        if (t === 3) return 3;    // 슈퍼 점프 타일이면 무조건 즉시 반환!
    }
    return hitType;
}

// 2. 메인 업데이트 루프에서의 분기 처리
let hitY = checkWall(ball.x, nextY, map);
if (!hitY) {
    ball.y = nextY; // 충돌 없으면 낙하
} else {
    if (ball.dy > 0) { // 바닥에 닿는 순간
        // 🔥 타일 종류가 3번(슈퍼 점프)이면 점프력을 1.6배로 증폭!
        ball.dy = (hitY === 3) ? jumpForce * 1.6 : jumpForce; 
        ball.dx = 0;
    }
}

✨ 결과 및 느낀 점

충돌 함수 구조를 조금 바꾼 것만으로도 게임의 레벨 디자인(Level Design)이 무궁무진하게 넓어졌습니다. 좁은 벽 사이를 통통 튕기며 올라가는 협곡 지형이나, 슈퍼 점프를 연속으로 밟아야 하는 퍼즐 요소를 직접 배열(2D Array)로 찍어내는 과정은 퍼즐을 맞추는 것처럼 즐거웠습니다. 플랫폼 게임의 본질인 '조작감'과 '충돌 물리'를 완벽하게 이해할 수 있는 프로젝트였습니다.
