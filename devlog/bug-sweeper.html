버그 스위퍼(Bug Sweeper) 개발일지

작성일: 2026-04-25 | 작성자: imgtocode

👿 프로젝트 개요

'버그 스위퍼'는 윈도우의 근본 게임인 '지뢰찾기'의 룰을 그대로 가져와, 숨어있는 치명적인 버그(지뢰)들을 피해 안전한 코드 영역을 확보하는 퍼즐 게임입니다. 2차원 배열을 이용한 그리드(Grid) 데이터 관리와, 우클릭을 활용한 깃발(디버깅) 시스템을 자바스크립트로 구현했습니다.

⚠️ 핵심 트러블슈팅: 연쇄적으로 빈칸 열기 (Flood Fill)

문제 상황: 유저가 주변에 버그가 하나도 없는 안전한 칸(0번 칸)을 클릭했을 때, 단순히 그 칸 하나만 열리는 것이 아니라 맞닿아 있는 다른 빈 공간들까지 연쇄적으로 쫘르륵 열리는 시원한 효과를 구현해야 했습니다. 단순한 반복문(for)만으로는 주변의 주변까지 끝없이 탐색하기가 매우 까다로웠습니다.

해결 방법: 재귀 함수(Recursive Function)를 활용한 Flood Fill 알고리즘을 적용했습니다. 클릭한 칸이 0이라면 주변 8방향을 검사하고, 아직 방문하지 않은 안전한 칸에 대해 자기 자신(함수)을 다시 호출하도록 설계하여 물감이 번지듯 맵이 열리는 로직을 완성했습니다. 


// 빈 공간을 연쇄적으로 여는 재귀 함수
function openEmptyCells(r, c) {
    // 1. 맵 범위를 벗어나거나, 이미 열린 칸, 깃발이 꽂힌 칸은 탐색 종료
    if (r < 0 || r >= rows || c < 0 || c >= cols || board[r][c].isOpen || board[r][c].isFlagged) {
        return;
    }

    // 2. 현재 칸 열기
    board[r][c].isOpen = true;
    revealedCount++;

    // 3. 현재 칸 주변에 버그가 하나도 없다면(0이라면) 8방향으로 재귀 호출!
    if (board[r][c].neighborBugs === 0) {
        for (let dr = -1; dr <= 1; dr++) {
            for (let dc = -1; dc <= 1; dc++) {
                // 제자리(0,0)를 제외한 모든 방향 탐색
                if (dr !== 0 || dc !== 0) {
                    openEmptyCells(r + dr, c + dc);
                }
            }
        }
    }
}

✨ 결과 및 느낀 점

단순히 네모난 칸을 클릭하는 UI 너머에 '재귀 함수'라는 아름다운 자료구조 로직이 숨어있다는 것을 깨달은 뜻깊은 프로젝트였습니다. Call Stack(호출 스택)의 한계를 고려해 그리드 사이즈를 설계하는 과정도 좋은 경험이 되었습니다. 다음 업데이트에서는 첫 클릭 시 무조건 버그가 걸리지 않도록, '첫 클릭 이후에 지뢰를 배치하는 안전 보장 로직'을 추가해 볼 계획입니다.

버그를 밟지 않고 모든 코드를 디버깅하세요!
