픽셀러너(Pixel Runner) 개발일지

작성일: 2026-05-10 | 작성자: imgtocode

🏃 프로젝트 개요

'픽셀러너'는 8비트 레트로 감성을 담은 무한 러닝 게임입니다. 끊임없이 생성되는 장애물인 '픽셀 버그'를 피해 달리는 것이 목표입니다. 단순히 달리는 것을 넘어, 시간에 따라 게임 속도가 빨라지는 점진적 난이도 시스템과 획득 시 일정 시간 무적이 되는 파워업 아이템 로직을 자바스크립트로 구현했습니다.

⚠️ 핵심 트러블슈팅: 다이나믹 애니메이션과 다리 움직임 구현

문제 상황: 캐릭터가 달리는 느낌을 주기 위해 단순한 이동이 아닌 역동적인 움직임이 필요했습니다. 하지만 매 프레임마다 모든 픽셀을 다시 그리는 방식은 계산 낭비가 심했고, 다리 움직임의 타이밍을 맞추는 것이 까다로웠습니다.

해결 방법: 전역 변수인 frameCount를 활용하여 모듈로(%) 연산을 통해 애니메이션 페이즈를 나눴습니다. 특히 캐릭터의 다리 픽셀을 그릴 때 특정 프레임 단계에서 특정 픽셀을 생략(return)함으로써, 뛰는 듯한 시각적 효과를 가볍게 구현했습니다. 


// 캐릭터의 달리기 애니메이션 구현 핵심 로직
playerPixel.forEach((row, ri) => {
    row.forEach((col, ci) => {
        if (col) {
            let drawY = player.y + ri * pSize;
            
            // 마지막 행(다리 부분) 처리
            if (ri === 4) {
                // 프레임 수에 따라 두 다리가 번갈아가며 생략됨
                const legPhase = Math.floor(player.animFrame / 6) % 2;
                if (player.grounded && (
                    (legPhase === 0 && ci === 1) || 
                    (legPhase === 1 && ci === 3)
                )) return; // 해당 다리 픽셀을 그리지 않음
            }
            ctx.fillRect(player.x + ci * pSize, drawY, pSize, pSize);
        }
    });
});

✨ 결과 및 느낀 점

중력 가속도(gravity)와 점프력(jumpForce)을 조절하며 가장 쾌적한 조작감을 찾는 과정이 마치 실제 물리 실험을 하는 것 같았습니다. 특히 아이템 획득 시 캐릭터의 크기가 커지며 일정 시간 장애물을 무시하는 무적 로직은 게임의 재미 요소를 한층 끌어올렸습니다.

Firebase 랭킹 시스템을 통해 유저들 간의 거리 경쟁을 유도했으며, 배경에 구름과 나무 같은 오브젝트를 서로 다른 속도로 스크롤(Parallax Scrolling)하게 배치하여 공간감을 더했습니다. 앞으로는 피버 타임 도입과 캐릭터 커스터마이징 기능을 추가해 볼 예정입니다.
