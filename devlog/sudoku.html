스도쿠(Sudoku) 개발일지

작성일: 2026-04-27 | 작성자: imgtocode

🧠 프로젝트 개요

'스도쿠'는 전 세계적으로 사랑받는 9x9 논리 퍼즐 게임입니다. 가로, 세로, 그리고 3x3의 작은 박스 안에 1부터 9까지의 숫자를 중복 없이 채워 넣는 것이 목표입니다. 이번 프로젝트에서는 단순한 UI 구현을 넘어, 랜덤하면서도 규칙에 완벽하게 맞는 퍼즐 맵을 동적으로 생성하고 유저의 입력을 실시간으로 검증하는 로직을 자바스크립트로 구현했습니다.

⚠️ 핵심 트러블슈팅: 백트래킹(Backtracking)과 유효성 검사

문제 상황: 초기에는 무작위로 빈칸에 숫자를 채워 넣는 방식을 시도했지만, 빈칸이 채워질수록 규칙이 꼬이면서 아예 풀 수 없는(Unsolvable) 상태의 스도쿠 보드가 만들어지는 문제가 발생했습니다. 무지성 랜덤 배치가 아닌, '규칙을 확인하고 아니면 되돌아가는' 똑똑한 알고리즘이 필요했습니다.

해결 방법: 백트래킹(Backtracking) 알고리즘을 도입했습니다. 특정 칸에 숫자를 놓아보고, 그 숫자가 스도쿠 규칙(가로, 세로, 3x3 박스 내 중복 없음)에 맞는지 검사합니다. 만약 막힌다면 다시 이전 단계로 돌아가 다른 숫자를 시도하는 방식입니다. 아래는 그 핵심이 되는 isValid (유효성 검사) 로직입니다. 


// 특정 위치(row, col)에 숫자(num)를 놓을 수 있는지 검사하는 함수
function isValid(board, row, col, num) {
    // 1. 가로(Row) 및 세로(Column) 중복 검사
    for (let i = 0; i < 9; i++) {
        if (board[row][i] === num || board[i][col] === num) {
            return false; // 중복 발견 시 배치 불가
        }
    }

    // 2. 3x3 서브 그리드(Box) 중복 검사
    // 현재 좌표가 속한 3x3 박스의 좌측 상단 시작점을 계산
    const startRow = Math.floor(row / 3) * 3;
    const startCol = Math.floor(col / 3) * 3;

    for (let i = 0; i < 3; i++) {
        for (let j = 0; j < 3; j++) {
            if (board[startRow + i][startCol + j] === num) {
                return false; // 박스 내 중복 발견 시 배치 불가
            }
        }
    }

    // 모든 조건을 통과했다면 배치 가능!
    return true; 
}

✨ 결과 및 느낀 점

시각적인 UI 작업도 중요하지만, 게임의 뼈대가 되는 '백트래킹' 같은 알고리즘을 직접 코드로 구현해 보니 논리적인 퍼즐이 풀려나가는 쾌감을 느낄 수 있었습니다. 특히 2차원 배열의 데이터를 다루고 깊은 복사(Deep Copy)를 처리하는 과정에서 자바스크립트의 참조 타입에 대한 이해도가 훨씬 높아졌습니다.
