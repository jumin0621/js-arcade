브릭 스택(Brick Stack) 개발일지

작성일: 2026-04-25 | 작성자: imgtocode

🟦 프로젝트 개요

'브릭 스택'은 좌우로 빠르게 이동하는 블록을 아래 블록과 정확히 일치시켜 가능한 한 높이 쌓아 올리는 게임입니다. 단순히 쌓는 것에 그치지 않고, 어긋난 만큼 블록의 너비가 실시간으로 줄어드는 긴장감 넘치는 시스템을 바닐라 자바스크립트로 구현했습니다.

⚠️ 핵심 트러블슈팅: 블록 커팅 알고리즘

문제 상황: 유저가 클릭했을 때, 현재 움직이는 블록이 아래 블록의 범위를 완전히 벗어났는지, 일부만 겹쳤는지 판단하고 그에 맞춰 블록의 너비를 갱신해야 했습니다. 좌표값의 절댓값 계산이 조금만 틀려도 블록이 공중부양하거나 엉뚱하게 잘리는 현상이 발생했습니다.

해결 방법: 현재 블록의 X 좌표와 아래 블록의 X 좌표의 차이인 difference를 먼저 계산했습니다. 이 차잇값이 현재 너비보다 크면 게임 오버를 처리하고, 작으면 너비에서 차잇값만큼을 뺀 새로운 너비를 다음 블록의 기준값으로 설정했습니다. 


// 블록 커팅 및 너비 계산 로직
function placeBlock() {
    const previousBlock = blocks[blocks.length - 2];
    const currentBlock = blocks[blocks.length - 1];

    // 아래 블록과 현재 블록의 중심 거리 차이 계산
    const difference = currentBlock.x - previousBlock.x;
    const absDifference = Math.abs(difference);

    if (absDifference >= currentBlock.width) {
        gameOver(); // 겹치는 영역이 전혀 없음
        return;
    }

    // 새로운 너비 = 기존 너비 - 어긋난 거리
    const newWidth = currentBlock.width - absDifference;
    
    // 잘린 후 남은 위치 조정 (겹치는 영역의 중앙으로)
    currentBlock.width = newWidth;
    currentBlock.x = previousBlock.x + (difference / 2);

    // 다음 스테이지 준비
    spawnNextBlock(newWidth);
    score++;
}

✨ 결과 및 느낀 점

픽셀 하나 단위로 결과가 달라지는 정교한 물리 계산을 구현하면서 상태 관리(State Management)의 중요성을 다시 한번 느꼈습니다. 성공적으로 스택을 쌓을 때마다 점진적으로 빨라지는 속도 조절을 통해 아케이드 게임 특유의 중독성을 확보할 수 있었습니다. 다음에는 콤보 시스템(연속 퍼펙트 시 너비 회복)을 추가하여 게임성을 높여볼 계획입니다.
