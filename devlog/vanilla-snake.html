바닐라 스네이크(Vanilla Snake) 개발일지

작성일: 2026-04-21 | 작성자: imgtocode

🕹️ 프로젝트 개요

모든 게임 개발의 기초가 되는 '스네이크'를 순수 자바스크립트(Vanilla JS)와 HTML5 Canvas만으로 제작했습니다. 외부 라이브러리 없이 배열(Array) 자료구조만으로 뱀의 성장을 구현하는 것이 이번 프로젝트의 핵심 과제였습니다.

⚠️ 핵심 트러블슈팅: 뱀의 몸통 추적

문제 상황: 머리가 움직일 때 몸통 조각들이 제각각 따로 노는 현상이 발생했습니다. 단순히 머리 좌표를 복사하는 것만으로는 뱀 특유의 '흐르는 듯한' 움직임을 만들 수 없었습니다.

해결 방법: unshift()와 pop()의 조합을 사용했습니다. 새로운 머리 위치를 배열의 맨 앞에 추가하고, 먹이를 먹지 않았다면 배열의 마지막 요소를 제거함으로써 뱀이 전진하는 효과를 완벽하게 구현했습니다. 


// 뱀 이동의 핵심 로직
const head = { x: snake[0].x + dx, y: snake[0].y + dy };
snake.unshift(head); // 새로운 머리 추가

if (head.x === food.x && head.y === food.y) {
    score += 10;
    generateFood(); // 먹이를 먹으면 pop을 하지 않아 몸통이 길어짐
} else {
    snake.pop(); // 먹이를 안 먹으면 꼬리 제거
}

✨ 결과 및 느낀 점

간단해 보이지만 Canvas의 requestAnimationFrame과 좌표 평면의 이해가 필수적인 작업이었습니다. 이제 JS-Arcade의 첫 번째 기초를 다졌으니, 다음은 좀 더 복잡한 물리 엔진이 들어가는 액션 게임에 도전해볼 생각입니다.
