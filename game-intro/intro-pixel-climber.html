픽셀클라이머 (Pixel Climber)

리듬 액션 · 무한 계단 등반 · 순수 JavaScript

픽셀클라이머는 단 두 개의 행동 버튼으로 다음 계단 방향을 읽어 올라가는 반응형 아케이드 게임입니다. 판정은 단순하지만 속도와 게이지 압박이 점점 강해져 집중력과 패턴 감각이 중요합니다.

핵심 규칙

  • 행동 버튼: turn / climb
  • 다음 계단 방향과 선택한 진행 방향이 일치하면 성공, 아니면 낙하
  • 성공 시 다음 계단으로 이동하며 점수와 콤보가 상승

조작 방식

  • 모바일 UI 버튼(btnTurn, btnClimb) 터치 지원
  • 키보드 단축: 좌/Z = turn, 우/X = climb
  • 우클릭 메뉴는 비활성화되어 입력 방해를 줄입니다.

스코어 · 콤보 · 게이지

  • 기본 점수는 성공 계단 1칸당 +1 (피버 중 +2)
  • 빠른 연속 성공으로 콤보가 누적되고 시각 효과가 강화됩니다.
  • 게이지는 시간 경과에 따라 감소하며, 행동 성공 시 회복됩니다.

피버 타임

  • combo % 50 === 0 달성 시 피버 ON
  • 피버 지속 프레임: feverTimer = 300
  • 피버 중 점수 효율 상승, 게이지 연출/파티클 효과 강화

게임 오버 조건

  • 잘못된 방향 선택 시 낙하 애니메이션 후 종료
  • 게이지가 0이 되면 자동 낙하로 게임 종료
  • 최종 기록은 오른 계단 수(score)로 집계됩니다.

연출 요소

  • 좌우 방향별 캐릭터 픽셀 아트 스프라이트
  • 무한 스크롤 구름과 카메라 추적으로 상승감 강화
  • 발판 성공/피버 발동 시 파티클로 타격감 제공

랭킹 시스템

  • 랭킹 저장 호출: saveGameScore("pixelclimber", nickname, score)
  • 닉네임 2자 이상 입력 후 등록 가능
  • 재시작 시 점수/콤보/게이지/피버 상태 모두 초기화

플레이 팁

  • 다음 발판 방향을 먼저 보고 입력하면 실수율이 크게 줄어듭니다.
  • 게이지가 낮을수록 안전 입력을 우선해 생존을 확보하세요.
  • 피버 직전 구간은 속도보다 정확도 위주로 운영하는 편이 효율적입니다.
