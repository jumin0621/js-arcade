실드 서바이버 (Shield Survivor)

슈팅 · 디펜스 서바이벌 · 순수 JavaScript

실드 서바이버는 화면 중앙의 코어를 지키며 사방에서 몰려오는 적을 격추하는 생존형 슈팅 게임입니다. 플레이어는 직접 이동하지 않고 조준 방향만 바꿔 자동 발사하며, 실드 체력이 0이 되면 게임이 종료됩니다.

기본 구성

  • 캔버스 크기: 360 x 400
  • 플레이어 코어는 화면 중앙 고정, 시작 실드 체력은 100%
  • 점수는 적 처치 시 누적되며 실드 잔량은 별도 HUD로 표시됩니다.

조준과 공격

  • 마우스 이동/터치 이동으로 목표 좌표(targetX, targetY)를 업데이트합니다.
  • 코어는 타겟 방향으로 조준선을 그리며, 별도 입력 없이 자동 사격합니다.
  • 연사 간격은 약 150ms이며 총알은 타겟 방향으로 직선 이동합니다.

적 종류와 패턴

  • 슬라임(약 60%): 느림, HP 1, 처치 +10점
  • 유령(약 30%): 지그재그 이동, HP 2, 처치 +20점
  • 폭탄(약 10%): 빠름, HP 1, 처치 +30점
  • 적은 사방 가장자리에서 랜덤 스폰 후 중앙 코어를 향해 접근합니다.

난이도 상승 요소

  • 초기 스폰 주기 spawnRate = 90 프레임
  • 시간이 지날수록 스폰 주기가 계속 감소(spawnRate--, 최소 20 근처)해 밀도가 증가합니다.
  • 적 이동 속도에도 score * 0.005 보정이 붙어 장기전일수록 압박이 커집니다.

충돌과 실드 시스템

  • 총알과 적은 거리 기반 충돌(hypot)으로 판정합니다.
  • 적이 코어 실드 반경(distToPlayer < 35)에 닿으면 체력이 감소합니다.
  • 일반/유령 충돌은 -10, 폭탄 충돌은 -20 체력 피해를 줍니다.
  • 실드 색상은 체력에 따라 초록 → 노랑 → 빨강으로 변경되어 위험도를 표시합니다.

연출 요소

  • 피격 및 처치 시 픽셀 파티클이 생성되어 타격감을 강화합니다.
  • 적 피격 시 짧은 흰색 파티클, 처치 시 적 색상 기반 대량 파티클이 발생합니다.
  • 코어 피격 시 미세 화면 흔들림 효과가 적용됩니다.

게임 종료와 랭킹

  • 실드 체력이 0이 되면 SHIELD BROKEN 모달과 함께 게임 종료됩니다.
  • 랭킹 저장은 saveGameScore("shieldsurvivor", nickname, score)를 사용합니다.
  • 닉네임은 최소 2자이며, 재시작 시 점수와 실드 상태가 초기화됩니다.

플레이 팁

  • 코어를 중심으로 작은 원을 그리듯 조준을 회전시키면 사방 접근 적을 고르게 처리할 수 있습니다.
  • 유령은 지그재그 때문에 근접 전 탄이 빗나가기 쉬우니 중거리에서 먼저 정리하는 편이 좋습니다.
  • 폭탄은 실드 피해가 크므로 다수 상황에서도 우선 제거 대상으로 잡는 것이 생존에 유리합니다.
